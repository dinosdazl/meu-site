Bem-vindo ao mundo da programação!

Aqui você vai aprender o básico de programação, lógica e algoritmos usando Python.

O que é Python?

Python é uma linguagem de programação. Com ela, podemos criar programas, jogos, sites e automatizar tarefas. Sua escrita é simples e boa para quem está começando.

Meu primeiro código

print("Olá, mundo!")

Esse comando mostra a mensagem "Olá, mundo!" na tela.

O que é um algoritmo?

Um algoritmo é uma sequência de passos para resolver um problema. Uma receita de bolo, por exemplo, segue uma ordem de instruções.

1. Sequência

Executar instruções em uma ordem.

print("Olá")
print("Tudo bem?")

2. Condição

Escolher o que fazer usando if e else.

idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

3. Repetição

Repetir instruções usando for ou while.

for numero in range(5):
    print(numero)
